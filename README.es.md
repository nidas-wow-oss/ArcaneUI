# ArcaneUI

Un cambio visual completo, estilo ArcaneBlue, para World of Warcraft 3.3.5a (WotLK): le da a las texturas, ventanas y marcos de unidad de Blizzard un estilo azul oscuro y compacto.

## Instalación

1. Descargá este repositorio (**Code → Download ZIP**).
2. Copiá la carpeta `ArcaneUI` en `World of Warcraft/Interface/AddOns/`.

## Uso

`/aui` abre las opciones.
