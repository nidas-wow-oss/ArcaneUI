# ArcaneUI

A complete ArcaneBlue visual overhaul for World of Warcraft 3.3.5a (WotLK): it reskins the Blizzard interface textures, windows and unit frames with a dark, compact blue style.

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `ArcaneUI` folder into `World of Warcraft/Interface/AddOns/`.

## Usage

`/aui` opens the options.
